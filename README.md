# powermode — переключатель режимов мощности CPU/GPU с иконкой в трее

Два режима для ноутбука на Linux (Ubuntu/GNOME):

| Режим | CPU (Intel RAPL) | GPU (NVIDIA) |
|---|---|---|
| `eco` | 45 Вт постоянно / 55 Вт пик | потолок частоты 1500 МГц |
| `max` | 70 Вт постоянно / 115 Вт пик (заводской пик Intel) | без потолка |
| `ultra` | 215 Вт / 215 Вт (аппаратный потолок RAPL) | без потолка |

`ultra` снимает все введённые нами ограничения: дальше процессор упирается только в охлаждение (троттлинг при ~100 °C) и блок питания. Прироста скорости относительно `max` обычно мало, а нагрев, шум и нагрузка на блок выше. Включайте, когда блок питания исправен, а охлаждение в порядке.

Значения подобраны под i7-12700H + RTX 3070 Mobile. Для другого железа поправьте числа в блоке `case` в файле `powermode`.

## Что внутри
| Файл | Назначение |
|---|---|
| `powermode` | Основной скрипт (`eco`/`max`/`status`), ставится в `/usr/local/bin`. Пишет лимиты в `/sys/class/powercap/intel-rapl:0/…`, для GPU вызывает `nvidia-smi -lgc/-rgc`. Выбранный режим сохраняет в `/etc/powermode`. |
| `powermode.service` | systemd-служба: применяет сохранённый режим при загрузке. |
| `powermode-sleep` | Хук сна (`/usr/lib/systemd/system-sleep/`): после пробуждения применяет режим заново, потому что прошивка может сбросить лимиты. |
| `powermode-tray` | Иконка в трее (Python + GTK + AyatanaAppIndicator), ставится в `~/.local/bin`. |
| `powermode-tray.desktop` | Автозапуск иконки при входе (`@HOME@` подставляет установщик). |
| `install.sh` / `uninstall.sh` | Установка и удаление. |

## Установка
```bash
cd ~/Documents/powermode
bash install.sh        # от обычного пользователя, sudo спросится внутри
```
Установщик поставит зависимости (если нет), скрипт, службу и хук сна, спросит про переключение без пароля, установит иконку и запустит её. Если иконка не появилась, перезайдите в сессию GNOME и проверьте `gnome-extensions list --enabled | grep appindicators`.

## Использование
```bash
powermode status        # текущее состояние (без sudo)
sudo powermode eco      # безопасный режим
sudo powermode max      # заводской пик
sudo powermode ultra    # все ограничения сняты
```
Или кнопка в трее: иконка → «Eco» / «Max» / «Ultra» (у Ultra иконка с предупреждением). Если не включали переключение без пароля, система спросит пароль окошком.

## Как устроена иконка
Скрипт `powermode-tray` (около 50 строк Python):
1. Создаёт `AyatanaAppIndicator3.Indicator` с символической иконкой темы (`power-profile-power-saver-symbolic` для eco, `power-profile-performance-symbolic` для max). В GNOME значок отображает расширение `ubuntu-appindicators`.
2. Строит меню `Gtk.Menu`: неактивная строка с текущим режимом, разделитель и два пункта «Eco» / «Max».
3. Клик по пункту вызывает `sudo -n /usr/local/bin/powermode <режим>`; если sudoers не настроен (пароль нужен), откатывается на `pkexec` (графический запрос пароля).
4. Раз в 10 секунд (`GLib.timeout_add_seconds`) читает `/etc/powermode` и обновляет иконку и подпись, так что смена режима из терминала тоже видна.

## Переключение без пароля
Установщик по желанию добавляет в `/etc/sudoers.d/powermode` одну строку:
```
<ваш_пользователь> ALL=(root) NOPASSWD: /usr/local/bin/powermode
```
Скрипт принадлежит root и принимает только `eco`/`max`/`status`, так что это единственное разрешение. Права выдаются только на него.

## Требования и ограничения
- Linux с systemd, GNOME (трей через расширение appindicator), Python 3 с `python3-gi`.
- CPU: Intel с RAPL (`/sys/class/powercap/intel-rapl:0`). Без него лимит CPU не меняется (будет предупреждение).
- GPU: NVIDIA с `nvidia-smi`. Лимит мощности (`-pl`) на ноутбучных картах обычно не поддерживается, поэтому ограничивается частота (`-lgc`).
- ⚠️ `max` ставьте только при исправном и достаточно мощном блоке питания и нормальном охлаждении. Если ноутбук отключает зарядку под нагрузкой, оставайтесь на `eco`.
- Не используйте вместе с другим управлением RAPL (`thermald`, свои службы `rapl-limit`/`power-limits`): они могут перезаписывать лимиты.

## Удаление
```bash
bash uninstall.sh
```
